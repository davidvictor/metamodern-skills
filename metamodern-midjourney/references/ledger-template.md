# Ledger template

Copy this skeleton to the brand's project directory as `midjourney.md` at intake. Replace every angle-bracket field. Store job ids, image URLs, resolved prompts, and codes; never store generated images in Git. When a run belongs to a brand-world gate, link the gate from here and keep the Midjourney record in this file.
