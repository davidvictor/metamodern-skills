# Midjourney instrument

Midjourney is an instrument the user operates in their own logged-in account. The method lives in `metamodern-midjourney`: the look kit built from the brand's approved imagery, the recipe block with current parameters fixed by a calibration run, the paste sheet the user runs one job at a time, the screen, and the per-brand ledger. This package keeps only the boundary that matters to a brand-world run.

1. A brand-world gate never depends on Midjourney. Gates lock on Higgsfield images.
2. A Midjourney result enters the Higgsfield chain only as a reference the director authorizes, with its job id and resolved recipe recorded in the brand's `midjourney.md` and linked from `brand-world.md`.
3. Locked brand-world plates are the first candidates for that brand's Midjourney style set; hand them over with their roles.
4. Nothing else touches Midjourney: no pooled accounts, unofficial APIs, or proxy services, and the agent never operates the user's session without their request in the current session.

Read the operating contract in `metamodern-midjourney` before any Midjourney work inside a brand-world run.
