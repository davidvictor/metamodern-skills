# Ledger template

Copy this skeleton to the brand's project directory as `brand-world.md` at Gate A. Replace every angle-bracket field. Never store generated images in Git; store job ids, element ids, and recipes. Two agents working the same brand record under their own agent heading inside each gate and never edit each other's locks.
