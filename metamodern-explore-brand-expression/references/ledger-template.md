# Run ledger template

One ledger per run, kept in the brand's project workspace. Record as the run happens; Director's words go in verbatim.

```markdown
# <Brand> brand expression run, <date>

Status: Draft
Owner: Designated creative director
Last reviewed: <date>

## Stage 1: Intake
Decisions (verbatim): ...
Inputs table: input, source, state (fixed, open, gap).
Logo media id and authorization date.
PRESERVE block (verbatim).

## Stage 2: Sheets
Brief shape: distinct bets, distance scale, or matrix.
Sheet table, side by side.
Gate: Director's words.

## Stage 3: Boards
Recipe: model, aspect, resolution, quality, references with roles, prompt blocks by name.
Jobs: index, job id.
Screen table: logo, wordmark, palette, leak, imagery rules, subject, device, spelling, tiles.
Recommendation stated before the question.
Gate: Director's words; forced pair.

## Stage 4: Refine
Base, named changes, where they may not go, screen fixes listed as changes.
Jobs, screen, lesson.
Gate: Director's words. Return path taken, if any.

## Stage 5: Expand
Surfaces, models read back from job records, adjustments.
Screen table per tile.
Gate: Director's words. Lock amendments.

## Stage 6: Language
Design language (nine lines), recipe bank, Figma build list.
Gate: acceptance.

## Stage 7: Closeout
Where brand facts were filed; where images were copied; method lessons for the package.
Credits spent; time.
```
