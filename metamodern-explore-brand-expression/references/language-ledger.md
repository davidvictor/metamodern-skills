# Language ledger

Use this as a starting hypothesis list, then record project-specific evidence in the run ledger. A phrase is not proven merely because it appears here. Verify it against the selected model and current provider behavior.

| Phrase pattern | Intended effect | Check |
| --- | --- | --- |
| "Image 1 is the approved logo ... reproduce it exactly wherever it appears; never redraw, restyle, recolor, or distort it" | Preserve the supplied mark | Compare every appearance with the source |
| "The wordmark is artwork and is never typeset; any headline face is for headlines only" | Keep generated type from replacing the wordmark | Inspect the smallest wordmark use |
| "Image 1 is a reference for the logo and its colors only, not a layout to copy" | Prevent the source sheet becoming the composition | Compare structure, not only content |
| A geometry rule stated positively and spatially | Preserve a defining device | Inspect every surface and crop |
| "Palette is fixed: ... nothing else" plus one role per colour | Hold palette and usage roles | Sample large fields and small labels |
| "<colour> used at five percent as a single fine accent" | Constrain proportion | Measure the resulting emphasis |
| "<colour> exists only as light inside the photograph" | Render colour as light rather than fill | Inspect the physical source of colour |
| An enumerated tile list repeated across sheets | Keep the board complete | Count every required tile |
| "Thesis ... Tension ... Lineage: <genres>" | Produce a coherent world | Screen for one readable direction |
| "Visual verbs: <three to five>" plus an internal-label rule | Shape form without printing labels | Check imagery and visible text separately |
| Exact text plus a spelling instruction | Reduce text drift | Read every visible word; prompting is not verification |
| "a portrait treatment with an invented person (not a real one)" | Avoid real-person likeness | Reject recognizable likeness |
| A concrete environment description | Prevent unwanted category objects from arriving with a generic room | Inspect the whole frame, not only the hero subject |
| "Reject the category's defaults: ... Failure to avoid: ..." | Make drift diagnosable | Critique against the named failure line |
| "Imagery: <treatment>; <subject>" as separate lines | Let treatment and subject change independently | Confirm both landed |
| "REFINE Image 2. Keep <list> identical. Change only <named changes>" | Preserve the base while refining | Compare unchanged regions directly |
| "Remove only X; leave clean space where it was; nothing else changes" | Make a subtractive refinement | Reject unrelated redraws |
| "Match Image 2's drawing treatment, type behaviour, colour roles, line weights, and finish exactly. Do not copy Image 2's layout" | Transfer a system to a new format | Compare treatment and layout separately |
| Adjectives without lineage or behavior | Risk a generic board | Add concrete genres, actions, and constraints |
| A mark described in words instead of passed as an image | Risk invented geometry | Require the approved asset |
| Studio, photographer, or competitor names as lineage | Risk imitation | Use transferable descriptors instead |
| A requested model or aspect | Risk provider substitution | Read the actual job record before attribution |
