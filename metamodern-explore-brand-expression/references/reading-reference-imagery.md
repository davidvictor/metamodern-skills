# Reading reference imagery

Use this only after an image is classified as aesthetic inspiration. Do not apply it to official identity assets, founder or product likeness references, content references, or edit targets whose subject must remain exact. The method separates transferable craft from subject matter so a reference does not become an instruction to reproduce its content.

## The rule

An aesthetic reference is a carrier for qualities, not an instruction to reproduce its subject. Read these qualities in order and write them down before any search or generation:

1. **Light.** Direction, temperature, quality (raking, diffuse, practical, backlit), and what the light does to the subject. Ask whether light itself is the real subject.
2. **Composition.** Field and figure, negative space, scale of the subject within the frame, focus falloff, where the eye enters and rests.
3. **Color.** The contrast logic first (warm on cool, light on dark, tone on tone), then the roles (field, figure, highlight, accent). Never reduce color to hex substitution; map roles, not swatches.
4. **Style.** Era, medium, finish, grade, grain, print or screen character, production value.
5. **Details.** Edge behavior (crisp, dispersing, blurred), texture density, imperfections kept on purpose, how the image rewards a closer look.

## Essence, then expansion

From those readings, write a one or two sentence **essence statement** in plain language ("light as substance; organic flow caught mid-motion; warm pale detail against a deep cool field; granular up close, calm at a distance"). Confirm the reading with one question when cheap ("the light, not the grass?").

Then generate an **expansion set**: new subjects that carry the essence and belong to the brand's own world. Reuse the reference subject only when the recorded borrowing boundary permits it, and never when the director or the source constraint forbids carryover. Reproducing the reference in brand colors is a failed translation even when it looks better than the original attempt. The goal is work that could sit beside the reference as a sibling, never as a copy.

## Mechanics

- This method controls which qualities may be borrowed and which subject boundaries remain fixed. The selected model's prompting guide controls prompt order, length, and whether treatment language belongs in text or is carried by the reference input.
- When the selected model expects treatment in text, make those attributes explicit enough to prevent regression to the subject's average. When its reference mode expects a subject-first or stripped prompt, follow that syntax without relaxing the borrowing boundary.
- Where the selected model accepts reference images, supply the actual image and instruct which attributes to keep and which to replace.
- Iterate one image at a time against the sharer's reactions; a sheet of six untested translations compounds error.
- Record the sharer's phrases about what they love verbatim; they outrank any inferred reading.

For an official portrait, identity asset, product reference, or edit target, skip this expansion method. State the immutable subject and identity details, use a model and reference mode that support them, and compare the result directly with the source before acceptance. Reject identity, likeness, mark, product, or required-content drift.
