# Vocabulary and interpretation

Choose a term because it preserves a distinction the recipient needs. A plain phrase is often more exact than an impressive label. Keep the user's own phrase when replacing it would discard taste, emotion, uncertainty, or multiple possible meanings.

## Cross-domain distinctions

| Distinction | What to preserve |
| --- | --- |
| Aim / means / artifact | The desired change, how it might happen, and what is produced are different. A deck may support a decision; the deck itself does not establish the decision's purpose. |
| Observation / interpretation / hypothesis | What was noticed, what it might mean, and an explanation that remains to be examined. |
| Need / preference / constraint | Something required for the outcome, something favored, and a boundary that limits choices. Do not promote a preference into a hard requirement. |
| Symptom / mechanism / cause | A visible effect, the process producing it, and an explanation of why it occurs. A complaint establishes none of the latter automatically. |
| Output / outcome / impact | A thing produced, a resulting change, and wider consequences. Delivering an output does not prove the outcome. |
| Tradeoff / contradiction | Competing benefits can require a choice without making the intent incoherent. A contradiction contains incompatible claims or requirements. |
| Scope / depth | Scope is what is included; depth is how thoroughly it is understood. A deeper prompt can stay within the same scope. |
| Consistency / uniformity | A coherent set of rules can allow variation. Uniformity makes elements the same. |
| Complexity / complication | Many interacting parts may be inherent; avoidable difficulty may come from how they are arranged or explained. Do not assume all complexity should disappear. |
| Agency / autonomy / accountability | Capacity to act, latitude to decide, and responsibility for decisions or outcomes. These are not interchangeable. |
| Confidence / certainty | Strength of belief or evidence is not proof. Preserve "might," "I suspect," and "I want to test." |

## Design and experience precision

- Information architecture organizes content and navigation; visual hierarchy directs perceived attention.
- An affordance concerns possible action; a signifier communicates where or how to act. A decorative cue is not necessarily either.
- Progressive disclosure reveals complexity when relevant; deferred setup postpones work. Neither is automatically the answer to overwhelm.
- Feedback communicates what happened; feedforward helps someone anticipate an action's result.
- Discoverability concerns finding an action; comprehension concerns understanding it; usability concerns accomplishing a task in context.
- Perceived performance is experienced speed; latency is delay; throughput is work completed per unit time. "Faster" does not identify which one matters.
- Kerning adjusts spacing between particular letter pairs; tracking adjusts spacing across a text range; leading concerns line spacing.
- Voice is a recognizable manner of expression; tone adapts it to a situation. Clarity should not erase personality or emotional force.
- Positioning concerns the place and meaning a brand or offering seeks with an audience; messaging expresses relevant claims; visual identity creates recognizable visual expression.

## Interpreting broad adjectives

| Words | Possible meanings to keep open | A useful expansion question |
| --- | --- | --- |
| Simple | Fewer choices, fewer steps, clearer structure, lower maintenance | Which burden should be reduced, for whom, and what complexity still serves them? |
| Premium | Craft, materials, restraint, service, distinctiveness, price positioning | Which observable qualities would justify this perception in this context? |
| Strategic | Connected to an objective, consequential tradeoffs, a longer horizon | Which decision would change if the underlying objective became clearer? |
| Authentic | Faithful to experience, credible, culturally situated, unforced | What would make the expression feel true to its author and audience? |
| Engaging | Attention, comprehension, participation, return behavior, emotional involvement | What kind of engagement matters, and what would be empty attention? |
| Scalable | Higher volume, more people, more contexts, repeatability | What must grow, and which limits would growth expose? |
| Intentional | A reason for choices, coherence, deliberate emphasis | What purpose should each choice serve, and which choices remain open? |

These are candidate interpretations. Clarify selects only supported meanings or preserves the ambiguity. Expand can explore alternatives but must not declare one to be the user's hidden true intention.
