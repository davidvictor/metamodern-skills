# Combine

Integrate the selected prompts, directions, or additions into one coherent prompt. Preserve substantive contributions while removing repetition and organizing the work.

## Account for the sources

Identify the shared intention, the selected sources, and any weighting instruction. Build a small internal inventory of distinct aims, requirements, examples, constraints, exclusions, uncertainties, and requested outputs. Include the original prompt when the user asks to add directions back into it.

“Combine all” preserves every substantive contribution; “use the strongest parts” authorizes selection. “Use option two as the foundation” makes that the organizing direction, while named additions remain intact. If material is missing, ask for it; do not invent what an earlier option contained.

## Integrate with judgment

Merge compatible contributions and deduplicate repeated wording. Preserve exact quotations, identifiers, quantities, and protected text where their precision matters. Keep hypotheses conditional and distinguish proposed additions from commitments.

For conflicts, use the user's stated priority or later correction when it resolves the issue. Otherwise preserve the alternatives as a comparison or conditional path if that serves the aim. Ask one focused question when a conflict prevents a coherent result. Do not silently choose between incompatible requirements or smooth away meaningful tension.

One prompt may request separate artifacts, workstreams, or stages. Preserve the requested collection or handoff structure rather than collapsing every output into one document. Do not add execution mechanics merely because the combined prompt is longer; use Prepare when requested.

## Return and verify

Return one standalone, copy-ready prompt. Compare it with the internal inventory: each selected contribution must be retained, merged without loss, or explicitly excluded under an authorized selection instruction. Meaning-preserving deduplication needs no change log.

Add a short note only for an unresolved conflict, material scope increase, or consequential omission. If the combined scope has become broad, make that visible without silently pruning it or splitting the work without permission. Shorten is a separate request to reduce wording, not a license to discard substance.
