# Figma Starter References

Starter files are optional project inputs, not bundled dependencies. In a Metamodern Agency checkout, read `integrations/figma-starters.md` for the private starter registry. Outside that checkout, use only a starter the user or project source register supplies. Reinspect the live file before using or describing its current state.

| Starter kind | Intended role |
| --- | --- |
| Editorial Document | Single-file project system and editorial document source |
| Deck System | Project Design library seed with editable slide-size recipes |
| Web System | Project-local web token, style, component, and recipe authority |
| Web Working | Standalone web exploration and feature examples |
| iOS System | Project-owned iOS system above Apple's external platform layer |
| iOS Working | Standalone phone and tablet examples |

Do not duplicate a starter until the current Project needs it. A duplicated starter becomes an independent project-local system. Publication, subscription, permissions, and consumer rebinding may require Figma UI work and must be verified afterward.
