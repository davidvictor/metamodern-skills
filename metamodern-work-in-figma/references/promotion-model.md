# Guidance Promotion

Design knowledge moves through three states so one Project's art direction or one correction does not silently become a universal rule.

## Candidate observation

Record what happened, where it happened, and the evidence: a correction, manual adjustment, repeated failure, successful construction pattern, or tool limitation. It applies nowhere else by default.

An agent may record or propose a candidate, but it must not add the observation to shared guidance or memory as a settled rule.

## Project rule

A candidate becomes a Project rule when the director confirms it for that Project or the approved Project brief requires it. Record the rule in the Project's `00 · Overview`, component documentation, recipes, or project instructions. Brand language, visual art direction, client governance, and most content treatments normally stop here.

## Shared Working Style

A Project rule becomes part of the shared Working Style only when the director identifies it as cross-Project or approves it during a Working Style review. Existing standing authorization may cover narrow, evidence-backed method corrections that preserve the Working Style's scope and design. Material changes to design, scope, or approval boundaries still require the director's decision.

Before proposing promotion, confirm that the pattern:

- is useful beyond one brand or deliverable;
- aligns with current Figma capabilities;
- preserves human editability without unnecessary process;
- has been structurally and visually proven in real work; and
- has a clear scope and boundary.

Repeated evidence strengthens a proposal but does not expand authorization. When a tool capability changes, verify it live before changing the Working Style. For an authorized method correction, edit the canonical repository package, forward-test the original case and one materially different case, validate and commit it, then reinstall and verify parity. Report the correction. Do not edit the installed copy directly or write memory without the director's explicit request.
