# Editorial Documents

Use Figma Design for reports, recaps, white papers, and publications. Declare whether the artifact is paginated or continuous. Paginated documents normally use one numbered top-level native frame per output page in reading order; continuous documents use a clearly declared long section-based frame.

Keep the working system, assets, canonical document, and review area in one file until performance, access, or ownership makes a split useful. Componentize small modules such as folios, labels, quotes, captions, source lines, statistics, visible text links, media frames, logo slots, and collage tiles. Keep rich copy as named text layers rather than forcing it into a text property that loses mixed formatting.

Declare the authoritative copy source in `00 · Overview`. Preserve approved copy verbatim unless editing is requested. If copy does not fit, recompose, split it, or add pages.

Every digital destination has a visible descriptive text link; an image hotspot can supplement but never replace it. Put source media and logos in independently selectable children inside clipped frames. For full-bleed photo work, use no frame padding and preserve crop control for each tile.

For a digital PDF, inspect the exported PDF for frame order, font rendering, links, and crops. For production requirements such as CMYK, bleed, PDF/X, or tagged accessibility, state the required external finishing. A Figma export is not automatically an accessible PDF.
