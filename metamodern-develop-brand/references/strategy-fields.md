# Strategy Fields

These fields help the workspace hold distinct parts of the strategic picture. They support internal reasoning; the Brand System publishes only the synthesis that is useful to apply.

| Field | Contract |
| --- | --- |
| Proposition | How the offer creates relevant value for a priority audience |
| Why | The core conviction or contribution behind the organization |
| Vision | The future condition the organization hopes to help make true |
| Mission | The organization's current role and action toward that future |
| Customers | Priority audience, buying context, roles, needs, and desired outcomes |
| Competitors | Direct alternatives, indirect alternatives, status quo, and category conventions |
| Position | The credible place the brand occupies through difference and proof |
| Values | Principles expressed through observable choices and behavior |
| Personality | The recognizable human character and behavioral traits of the brand |
| Promise | The credible commitment customers can consistently expect |
| Voice | The stable verbal character of the brand, with tone adapting by context |
| Messages | The ordered ideas and proof the audience should understand and remember |

## Useful distinctions

- Proposition explains the value made by the offer for a priority audience. Position identifies the credible place the brand can hold relative to alternatives. Promise is the ongoing customer commitment the organization must reliably deliver.
- Why states the conviction or contribution behind the organization. Vision names the future condition it wants to help create. Mission describes its current work toward that future.
- Values are principles visible in choices and behavior. Personality is the human character those choices make recognizable. Voice is how that character sounds in language, while tone changes with the situation.
