# Platform Boundaries

| System | Authority |
| --- | --- |
| Git | Canonical skill, project rules, workspace, accepted Brand System, manifests, and links |
| Design tool | Editable identity, explorations, visual system, and application artifacts |
| Website platform | Website canvas, CMS, review branches, and deployed state |
| Record system | Client, project, proposal, time, invoice, and engagement facts |

Read the project's authority and relevant integration guide before acting in a system. In an Agency checkout, `governance/operating-authority.md`, `brand/foundation.md`, and the relevant integration guide may provide those adapters. Outside that checkout, use the installer's equivalent sources without assuming those relative files exist.
