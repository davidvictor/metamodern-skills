# Existing brand inventory

For existing-brand documentation, use [the documentation guide](../existing-brand-documentation.md) to recover explicit source answers, inspect rendered expression, and distinguish evidence gaps from production or redesign decisions.

## Helps resolve

What is already worth preserving, what evidence is authoritative, and which gap has the greatest practical cost.

## Useful when

An established or partial brand needs completion, a refresh is under consideration, or sources disagree.

## Review first

Editable Figma sources, accepted guidance, current priority applications, website evidence, and dated historical material.

## Prompt bank

- Which parts feel settled enough that changing them would destroy useful equity?
- Which sources are editable authority, accepted guidance, current application, or historical evidence?
- Where does the brand work best today?
- Where does it become inconsistent, incomplete, or hard to apply?
- Which missing artifact is blocking real work now?

## Method

Map relevant artifacts by source type and current use. Separate reliable equity from stale, incomplete, or conflicting evidence. Note only gaps that affect the current objective.

## Synthesis

Name settled elements, unresolved questions, and the smallest next set of cards or proofs that can reduce uncertainty.

## Contributes

A working inventory, source hierarchy, and scoped completion plan.

## Cautions

Do not treat a live application as accepted strategy, or replace useful equity merely because an artifact is old.
