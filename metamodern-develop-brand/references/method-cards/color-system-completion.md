# Color system completion

In existing-brand documentation, describe available color evidence and unresolved source details without completing a new palette. Follow the documentation boundary in the color method; the candidate and canonical-value decisions below belong to requested development work.

## Helps resolve

Whether the color system has clear roles, preserves useful recognition, and works in the contexts that matter.

## Useful when

Existing colors are incomplete, roles are ambiguous, or a change in color would materially improve application.

## Review first

Existing color evidence, accepted strategy, production requirements, accessibility needs, and priority digital and print contexts.

## Prompt bank

- What emotional and functional jobs must color perform?
- Which existing colors carry recognition worth preserving?
- Which neutrals support content and hierarchy?
- Where do accents or semantic roles add real clarity?
- Which real contexts will expose contrast, reproduction, or consistency failures?

## Method

Follow the color method to define only the roles and values the system needs. Test candidates in real contexts before documenting a compact usable set.

## Synthesis

State each retained role, its canonical value, the required checks, and the contexts that informed the decision.

## Contributes

Color guidance that can be carried into the Brand System and downstream work.

## Cautions

Do not import palette tables or add colors to create the appearance of a fuller system. Derived values must remain mechanically tied to the canonical value.

## Provenance

Independently written Metamodern method card.
