# Color Method

For existing-brand documentation, record observed colors, variants, contexts, and supported role interpretations. Keep sampled implementation values distinct from authoritative specifications; do not invent conversions, remove colors, or develop candidates. The completion/change sequence below does not apply to documentation alone.

Use color as a selective part of the identity system. Work through this sequence when color is being completed or changed:

1. Establish strategic, emotional, and functional jobs.
2. Audit existing color equity.
3. Develop original candidate directions when a change is useful.
4. Assign core, neutral, accent, and semantic roles.
5. Build supporting neutrals, tints, and shades only where needed.
6. Remove excess colors.
7. Record one canonical value and derive conversions mechanically.
8. Test contrast, color-vision behavior, screen use, print, and gamut as applicable.
9. Prove the system in real contexts.

Keep the system small enough to apply reliably. Document the role and canonical value of each retained color so implementation does not introduce unreviewed variants.
