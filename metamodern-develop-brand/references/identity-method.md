# Identity Method

For existing-brand documentation, inventory observed elements, variants, roles, sources, and source limits. Do not select new principles or force retain/refine/create decisions; the development steps below apply only when identity change is requested. A production-source gap is not a reason to redesign the brand.

Begin with an inventory of settled equity. Before proposing a change, identify what people recognize, what already works, and what editable evidence supports it. For every relevant element, choose to retain it, refine it, or create it anew.

Translate accepted strategy into a small set of identity principles that can guide choices. Develop alternative visual territories only when they make a real decision easier to judge. A territory is evidence for a decision, not a required creative phase.

Address mark, typography, color, imagery, graphic devices, layout, iconography, and motion only where each helps the brand. Review the selected elements for strategic coherence, distinctiveness, legibility, accessibility, reproduction, licensing, and behavior in priority contexts.

Use `metamodern-explore-brand-expression` to translate strategy into expression sheets, boards, a selected direction, and design language when the work benefits from exploration. Otherwise develop the needed territories, direction, and design language through this identity method. Use application proofs to test the system in context. Application proof is a review role; an accepted, editable, verified proof can become the production foundation for the applicable downstream capability.
