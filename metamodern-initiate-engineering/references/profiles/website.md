# Website profile

Use when the named task concerns a public or editorial site without application behavior that warrants an app foundation.

Inspect the current site, repository or site platform, content/design authority, editing and publishing boundary, analytics, forms, locale and accessibility needs, and available preview path. Ask only about CMS/editing, form delivery, domains, hosting, analytics, integrations, and publishing when the named task depends on them.

Keep the intake short. Do not require a database, account model, billing, multi-repository setup, or a full design system merely because the work is a website. Client-facing visual work uses the accepted Brand System and its owning capability; an independent nonvisual engineering task may proceed while visual direction remains incomplete.
