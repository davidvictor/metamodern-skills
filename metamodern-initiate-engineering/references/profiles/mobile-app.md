# Mobile application profile

Use when the named task has a native mobile surface or device-specific behavior.

Inspect current platforms, app identifiers, repository state, build/signing access, device or simulator availability, backend boundary, and release path. Ask only when relevant about target platforms, offline behavior, push notifications, camera/location/storage permissions, deep links, accessibility, analytics, subscription/store obligations, and migration from existing clients.

Keep the starter open until the named task needs a choice. A missing platform decision, signing access, or device runtime can yield a concrete discovery handoff. Do not substitute MakerKit or web-app infrastructure for a mobile foundation.
