# Local annotations (optional)

Annotations are an explicit local workspace capability, disabled by default. They cover only the actual Library and Inspect pages. Workspace modules and Compare, Responsive, Gallery, Present and Design are excluded even when Inspect remains the saved view. Product and public/offline builds must replace `__STUDIO_LOCAL_ANNOTATIONS__` with literal `false`; the Vite host enables it only for `serve` with `STUDIO_LOCAL_ANNOTATIONS=1`. The Next host enables it only during explicit development, never static export or production. Enabling a product adapter alone never loads Agentation.

Declare `adapter.annotations` with a stable product `id`, `repository`, optional `defaultEnabled`, optional `safeValues(context)` and `resolveSource(context, annotation, scope)`. Source resolution returns `repository?`, `owner`, `confidence` (`verified`, `candidate`, `unresolved`), `paths` and optional `candidates`. Use registered, source-owned maps; vendor source hints may identify compiled bundles. Never invent original lines, treat a selector as a command, infer an implementation owner from a story file, or broaden example scope when source resolution fails. The host stores resolved source separately from the original raw annotation and requested scope. Shared scope with unknown implementation must remain unresolved.

`safeValues` must whitelist only safe enum, select, numeric and boolean values. Without it, only numeric and boolean resolved property values are captured. Free text and structured product state are excluded. Design and draft values are represented by fingerprints. Password and explicit `[data-private]`/`[data-studio-private]` targets cannot be annotated. Semantic owner markers are inherited from the closest ancestor (`data-studio-anchor`, `data-studio-component`, `data-slot`, `data-kit-component`, `data-kit-example`, `data-test`, `data-testid`, `data-preview-block`). These identify observations, not trusted source paths. Product portals should supply explicit safe ownership markers or a `resolveOwner` callback; unresolved ownership remains honest.

The preview entry compile-guards its optional `createAnnotationClient({load: () => import("./studio/annotations/runtime"), resolveOwner?})` and passes the returned client as `connectStudioFrame`'s `handlers.annotations`. The framework-free client has no listeners or vendor import before selection. `connectStudioFrame` negotiates `annotations` on the existing `studio-preview/1` channel, preserving parent/origin/window/instance checks. The host accepts upsert/delete/clear only from its selected generation and immutable context fingerprint. Events are capped at64 KiB and durable records at32 KiB; errors ask for shorter feedback without truncating comments. Acknowledged revocation or destruction of the selected frame precedes activation of another document. Superseded imports cannot mount or emit.

One collapsed Agentation3.1.2 runtime mounts in Studio or one selected preview. Inspect registers its current ready runtime. Library uses its expanded dialog, with at least360×480 child CSS pixels, original dimensions disclosed, and its existing inline-frame budget released. Expanded views recreate product state and may change responsive layout. Availability toggles never remount a preview. Host controls are docked in a reserved strip under the Studio top bar, never floating over the stage or Details, and the vendor control keeps clear of an open Details panel; they portal into the expanded Base UI dialog while one is open; vendor popups use active same-document overlay content as their `portalContainer`.

The host owns durable notes under `studio-feedback/1:<product>:<origin>`, the browser preference, source/scope review, enriched combined Markdown and a selectable clipboard fallback. Marker rehydration uses Agentation's exported `saveAnnotations` helper with exact-context notes before mounting. Notes from other contexts stay in review without guessed placement. Storage failures retain notes in memory for the current document; copy before closing the tab. Session generations and frame instances are authentication provenance, not durable identity. A document or preview without a measured size (a restored or background tab at 0 x 0) starts no session until it has one; refusal reasons name the actual problem, and only an oversized command reports saved marker data.

No endpoint, webhook, MCP or remote send is configured. Native vendor clipboard is disabled, Copy/Submit open host review, global vendor shortcuts are disabled, and vendor settings are hidden and capture-blocked. The integration clears vendor webhook/autoclear settings before mounting. Product fixture networking and storage isolation remain unchanged. Feedback does not grant merge/release/publication authority.

Verify with focused annotation model/client tests, both host type/lint/build checks, `npm run acceptance:annotations` in a composed Vite receiver, applicable shell acceptance, hostile-env production graph exclusion, and fresh/prior-version updater proof. The focused browser journey requires Playwright (or `PLAYWRIGHT_MODULE`) and writes a measured report; no fixed sleeps or private product material are used. Product acceptance must additionally prove its real portal/focus behavior, source mappings, context revocation, isolation and paired performance budgets.

Capture fidelity includes a digest of every resolved input before redaction, safe registered numeric/enum/color design inputs, safe literal CSS token overrides, and explicit omitted-key/context disclosure. Thus changing an omitted private value still revokes a pending editor. A preview is unavailable for annotation while a replacement is staged, a prior specimen is retained after failure, or values/appearance/draft inputs lack a successful matching acknowledgement.

Marker hydration is bounded to the64 KiB transport envelope; excess markers remain in host review/export with a notice. Private selection is blocked before vendor capture, including targets with private descendants or nearby private siblings. Area/multi-selection is unavailable in a document containing private content. Rejected native state is purged and reseeded with accepted notes. Studio annotation mode temporarily prevents pointer entry into embedded frames; choose the preview target to annotate product content. Public/offline and locally disabled expansion retains natural specimen dimensions.
