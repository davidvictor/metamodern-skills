# Generic Design editor evidence

Only owned synthetic controls and product fixtures appear here. No private product source, recipes, assets or target mappings are included.

`browser-proof.json` records four Chromium/WebKit Vite/Next editing journeys and twelve native-width/coarse-pointer checks. `browser-delta.json` records the bounded footer/caption, component gesture and declared-slot correction on the next source freeze. Earlier behavior proof is retained with its distinct freeze rather than represented as a re-test. `browser-raw-input.json` records the final controlled invalid-text recovery checks in both hosts and engines. The subsequent saved/source-seeding change is covered by a pure regression; it does not reinterpret these earlier browser freezes. Screenshot hashes are in `artifacts.json`.

The proof covers generic controller/frame behavior, not canonical direction persistence, private integration, export receivers, deployment or user acceptance. Browser console errors from intentionally missing stylesheet requests are expected failure evidence; page errors were absent. The one-shot opaque callback rejection is not claimed by the broad independent matrix.

`browser-selected-basis.json` binds the final shared preview guard to source and served-module hashes: after a failed source compilation and repaired working draft, Present and Compare’s source pane stay explicitly unavailable rather than mounting an uncompiled substitute.
